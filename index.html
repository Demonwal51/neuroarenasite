01 COMPRENDRE

        


            
Le machine learning, c’est quoi ?

            
Le machine learning, ou apprentissage automatique, est une branche de l’intelligence artificielle. On entraîne un modèle sur des données pour qu’il repère des régularités et produise des prédictions.

            
Dans un programme classique, on écrit des règles. Avec le machine learning, un algorithme ajuste les paramètres du modèle à partir d’exemples. Le modèle peut ensuite traiter de nouveaux cas.

            
Un exemple : détecter les spams

            
On fournit des e-mails étiquetés « spam » ou « non-spam ». Le modèle apprend des associations entre leurs caractéristiques et ces catégories.

            
Pour un nouvel e-mail, il prédit une catégorie. Il peut se tromper : une prédiction n’est pas une certitude.

02 L’APPRENTISSAGE

        


            
De la donnée au résultat.

            
Quatre grandes étapes pour construire et utiliser un modèle.

            
ÉTAPE 01

            
Préparer les données

            
Collecter des exemples pertinents, corriger les erreurs et réserver des données pour la validation et le test.

            
ÉTAPE 02

            
Entraîner le modèle

            
Le modèle produit des réponses sur les exemples d’entraînement. L’algorithme ajuste ses paramètres pour réduire les erreurs.

            
ÉTAPE 03

            
Évaluer sur de nouveaux cas

            
La validation aide à choisir les réglages. Un jeu de test séparé permet ensuite d’évaluer la capacité à généraliser.

            
ÉTAPE 04

            
Utiliser et surveiller

            
Le modèle fait des prédictions sur de nouvelles données. On surveille ses performances, car les situations peuvent évoluer.

        

        
03 LES MÉTHODES

        


            
Trois façons d’apprendre.

            
Supervisé

            
Chaque exemple est accompagné de la réponse attendue. Le modèle apprend à prédire une catégorie ou une valeur.

            
Exemple : détecter les spams.
            
Non supervisé

            
Les données n’ont pas de réponse attendue. On cherche des structures ou des groupes similaires.

            
Exemple : regrouper des documents.
            
Par renforcement

            
Un agent effectue des actions et reçoit des récompenses. Il apprend une stratégie pour améliorer ses résultats.

            
Exemple : jouer dans un simulateur.
            
Les limites à connaître. Des données biaisées peuvent entraîner des résultats biaisés. Un modèle peut aussi trop mémoriser ses exemples : c’est le surapprentissage. Réussir sur les données d’entraînement ne garantit pas de réussir sur des données nouvelles.
